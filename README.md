# Recipe Delivery
Приложение с рецептами, где для рецептов можно заказать продукты в нужном количестве.

## QuickStart для android
### Скачать RecipeDelivery-apk.rar
### Распаковать файл
### Установить APK-файл на amdroid телефон


## Структура файлов lib/
### authorization - страничка с входом/авторизацией
### breakfast - страничка с рецептами для завтрака
### dinner - страничка с рецептами для ужина
### lunch - страничка с рецетпами для обеда
### main_menu - главное меню
### pancakes - рецептов оладьев
### settings - страничка с настройками
